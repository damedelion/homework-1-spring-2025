# Отчет о тестировании музыкального сервиса NovaCode

Ссылка: [nova-music.ru](http://nova-music.ru)


## Навбар

#### Тестовое окружение

- Браузер: Safari. Version 18.3 (20620.2.4.11.5)

### Левая секция навбара

В левой секции навбара присутствует логотип сервиса, название и несколько ссылок, которые осуществляют навигацию  по сайту: переход на главную страницу, переход на страницу поиска.

- При нажатии на кнопку "Главная" отображается главная страница, а кнопка "Главная" подчеркивается оранжевым цветом
![2-1-1](img/navbar/2-1-1.png)

- При нажатии на кнопку "Поиск" отображается страница поиска, а кнопка "Поиск" подчеркивается оранжевым цветом
![2-1-2](img/navbar/2-1-2.png)

- При нажатии на название или логотип сервиса отображается главная страница
> [!WARNING]
> БАГ. На логотип нельзя нажать.

- При наведении на название сервиса, кнопку "Главная", "Поиск" текст кнопки затемняется
![2-1-3](img/navbar/2-1-3.png)

- При уменьшении размера ширина экрана/браузера, а также на мобильных устройствах кнопки "Главная", "Поиск"  скрываются и перемещаются в sidebar справа
![2-1-4-1](img/navbar/2-1-4-1.png)
![2-1-4-2](img/navbar/2-1-4-2.png)

- При нажатии на кнопку "Войти" отображается страница авторизации, а кнопка "Войти" подчеркивается оранжевым цветом

![2-2-2](img/navbar/2-2-2.png)

- При уменьшении размера ширина экрана/браузера, а также на мобильных устройствах кнопки "Войти", "Регистрация"  скрываются и перемещаются в sidebar справа
![2-2-3-1](img/navbar/2-2-3-1.png)

- При нажатии на аватарку пользователя отображается страница профиля пользователя

- Sidebar не скрывается при нажатии на область вне панели

## Поиск

#### Тестовое окружение

- Браузер: Safari. Version 18.3 (20620.2.4.11.5)

### Строка поиска

Место ввода поискового запроса, под которым располагается кнопка "Искать".

- При клике на строку поиска происходит выделение инпута синим
![1-1-1](img/search/1-1-1.png)

- При вводе символов в поисковую строку подсказки не появляются
![1-1-2](img/search/1-1-2.png)

- Если в стркое поиска введен запрос, то снизу, в блоке с результатом поиска, отображаются совпадения
![1-1-3](img/search/1-1-3.png)

- При наведении на кнопку "Искать" затемнения/выделения не происходит

- При клике на кнопку "Искать" затемнения/выделения не происходит

- Если нажать на кнопку "Искать" и если в поисковой строке ничего нет, то отобразится подсказка "Заполните это поле" на языке браузера

![1-1-6](img/search/1-1-6.png)

- При вводе в строку поиска запроса, содержащего цифры, отображаются найденные совпадения (если они есть)
![1-1-7](img/search/1-1-7.png)

- При вводе в строку поиска запроса на русском языке отображаются найденные совпадения (если они есть)
![1-1-8](img/search/1-1-8.png)

- При вводе в строку поиска запроса, содержащего символы из utf, отображаются найденные совпадения (если они есть)
![1-1-9](img/search/1-1-9.png)

- Нажатие на клавишу "Enter" инициирует логику поиска

- Ввод длинного запроса (32901 символа) не ломает поиск
![1-1-11-1](img/search/1-1-11-1.png)
![1-1-11-2](img/search/1-1-11-2.png)

- При вводе пробелов в строку поиска отображается панель "Ничего не найдено"
![1-1-12](img/search/1-1-12.png)

- Регистр символов введенной строки не влияет на результат поиска
![1-1-13-1](img/search/1-1-13-1.png)
![1-1-13-2](img/search/1-1-13-2.png)

### Блок с результатом поиска

Раздел страницы, содержащий три блока с найденными совпадениями для артистов, треков и альбомов.

- Если в блоке с результатом поиска отображаются совпадения и если в строке поиска ввести запрос и нажать кнопку "Искать", то в блоке с результатом будут отображаться совпадения для нового запроса

> [!WARNING]
> БАГ. Если в блоке с результатом поиска уже отображаются совпадения, среди которых есть совпадения с треком, и если ввести новый запрос, для которого не будет найдено ни одного трека (при этом альбом или артист может быть найден), то в блоке с результатом появится трек/треки, относящиеся к последнему запросу, для которого был найден трек/треки.
> ![1-2-1-1](img/search/1-2-1-1.png)
> ![1-2-1-2](img/search/1-2-1-2.png)

- Если в поисковой строке ввести запрос, для которого не будет ничего найдено, то отобразится блок с надписью "Ничего не найдено" и подсказкой "Попробуйте поискать что-то другое."
![1-2-2](img/search/1-2-2.png)

- При загрузке страницы блок скрыт


## Профиль

Перейти в профиль можно по клику на аватар в навбаре.

#### Тестовое окружение

- Браузер: Yandex. Version 24.7.3.1253 stable (64-bit)

### Подписки

- При клике на кнопку "Подписки" в карточке профиля осуществляется переход на страницу подписок пользователя.

- Если пользователь ни на что не подписан, то показывается сообщение, что в этом разделе отобразятся его подписки, когда он подпишется на что-либо.
![profile-1-1](img/profile/profile-1-1.png)

- После подписки на исполнителя он отображается на странице подписок пользователя. Подписка осуществляется на странице артиста путем клика на кнопку "Нравится" в карточке артиста.
![profile-1-2](img/profile/profile-1-2.png)
![profile-1-3](img/profile/profile-1-3.png)

- После подписки на альбом он отображается на странице подписок пользователя. Подписка осуществляется на странице альбома путем клика на кнопку "Нравится" в карточке альбома.
![profile-1-4](img/profile/profile-1-4.png)
![profile-1-5](img/profile/profile-1-5.png)

- После подписки на плейлист он отображается на странице подписок пользователя. Подписка осуществляется на странице плейлиста путем клика на кнопку "Нравится" в карточке плейлиста.
![profile-1-6](img/profile/profile-1-6.png)
![profile-1-7](img/profile/profile-1-7.png)

- При отмене подписки исполнитель, альбом или артист удаляется со страницы подписок.

### Настройки профиля

- При клике на кнопку "Настройки профиля" в карточке профиля осуществляется переход на страницу настроек профиля.

- При клике на кпопку "Загрузить изображение" появляется возможность выбора фото из файлов.
![profile-2-1](img/profile/profile-2-1.png)

- После выбора аватара через диалог выбора файла и клика по кнопке "Загрузить изображение" происходит переход на сраницу с карточкой профиля. Аватар изменяется на загруженный в карточке и правом углу навбара.
![profile-2-2](img/profile/profile-2-2.png)

- При загрузке непредусмотенного формата аватара по клику по кнопке "Загрузить изображение" высвечивается сообщение о некорректном вводе.
> [!WARNING]
> БАГ. При попытке ввода непредусмотренного формата аватара отсутствует сообщение об ошибке.

- После внесения изменений в логин и клика на кнопку "Сохранить" происходит переход на страницу с карточкой профиля. Логин в карточке профиля изменяется на введенный.
![profile-2-3](img/profile/profile-2-3.png)
![profile-2-4](img/profile/profile-2-4.png)

- Если ввести в инпут логина символы, отличные от латинских букв, цифр и нижнего подчеркивания, или логин размера не в пределах от 4 до 16 символов и кликнуть на кнопку "Сохранить", высвечивается сообщение об ошибке.
> [!WARNING]
> БАГ. При некорректном вводе логина сообщение об ошибке выходит за пределы инпута логина и имеет нечитаемый (красный на синем фоне) цвет.
![profile-2-5](img/profile/profile-2-5.png)
![profile-2-6](img/profile/profile-2-6.png)

- Если ввести в инпут логина уже существующий и кликнуть на кнопку "Сохранить", высвечивается сообщение об ошибке c указанием, что профиль с таким логином уже существует.
> [!WARNING]
> БАГ. При изменении логина на уже существующий высвечивается сообщение о неизвестной ошибке, сообщение находится под кнопкой "Сохранить" и имеет нечитаемый (черный на синем фоне) цвет.
![profile-2-7](img/profile/profile-2-7.png)

- После внесения изменений в почту и клика на кнопку "Сохранить" происходит переход на страницу с карточкой профиля. Почта изменилась на введенную, что можно проверить в настройках профиля.
![profile-2-8](img/profile/profile-2-8.png)

- Если ввести невалидные форматы почты и кликнуть на кнопку "Сохранить", высвечиваются сообщения с подсказками.
![profile-2-9](img/profile/profile-2-9.png)

- Если ввести в инпут почты уже существующую  и кликнуть на кнопку "Сохранить", высвечивается сообщение об ошибке c указанием, что профиль с такой почтой уже существует.
> [!WARNING]
> БАГ. При изменении почты на уже существующую высвечивается сообщение о неизвестной ошибке, сообщение находится под кнопкой "Сохранить" и имеет нечитаемый (черный на синем фоне) цвет.
![profile-2-10](img/profile/profile-2-10.png)

## Плеер

#### Тестовое окружение

- Браузер: Mozilla Firefox 135.0

### Воспроизведение трека (левая часть)

В левой части плеера есть три функциональные кнопки: "предыдущий трек", "воспроизведение/пауза", "следующий трек".

* Если пользователь не авторизован плеер **отображаться не будет**;
* При наведении кнопки: "предыдущий трек", "воспроизведение/пауза", "следующий трек", **затемняются**:<br>
![pleer1](img/pleer/pleer1.png)
* При нажатии на кнопку "предыдущий трек" **начинает играть предыдущий трек**;
* Если трек не играет, то при нажатии на кнопку "воспроизведение/пауза", он **начинает играть, изображение кнопки меняется**:<br>
![pleer2](img/pleer/pleer2.png)
* Если трек играет, то при нажатии на кнопку "воспроизведение/пауза", он **ставится на паузу, изображение кнопки меняется**:<br>
![pleer3](img/pleer/pleer3.png)
* При нажатии на кнопку "следующий трек" **начинает играть следующий трек**;
* При переключение трека **меняется информация о треке (автор, название трека, картинка)**.
* При перезагрузке страницы трек, который играл последний, должен сохраняться.
> [!WARNING]
> БАГ. При перезагрузке страницы трек, который играл последний, не сохраняется<br>

### Воспроизведение трека (слайдер)

Слева от слайдера отображается текущее время трека, а справа — его общая длительность.

* Когда играет трек, **ползунок слайдера меняет свое положение**:<br>
![pleer4](img/pleer/pleer4.png)
* Когда играет трек, **текущее время трека изменяется**:
* Если сдвинуть ползунок, то **текущее время трека должно измениться**:
> [!WARNING]
> БАГ. Текущее время трека не изменяется<br>
![pleer5](img/pleer/pleer5.png)
* Если сдвинуть ползунок, а потом нажать на кнопку "воспроизведение/пауза" **время изменится**;
* Если во время воспроизведения сдвинуть ползунок, **трек начнет играть с новой позиции**;
* Обводка плеера **должна быть равномерной**:
> [!WARNING]
> БАГ. Обводка плеера не равномерная<br>
![pleer6](img/pleer/pleer6.png)
* Можно использовать "стрелки" для перемотки слайдера трека.

### Взаимодействие с треком

Справа от информации о треке, есть три функциональные кнопки: "лайк", "в плейлист", "поделиться".

* При наведении кнопки: "лайк", "в плейлист", "поделиться", **затемняются**:<br>
![pleer7](img/pleer/pleer7.png)
* Если трек лайкнут, то кнопка "лайк" **затемнена и трек добавляется в любимые треки пользователя**:<br>
![pleer8](img/pleer/pleer8.png)
  + Если трек лайкнут, то при наведении **внешний вид кнопки лайк не изменяется**; 
  + Если трек лайкнут, то при нажатии на кнопку "лайк" перестает затемняться и **трек удаляется из любимых треков пользователя**;
* При нажатии на кнопку "в плейлист" **открывается модальное окно для выбора плейлиста**:<br>
![pleer9](img/pleer/pleer9.png)
  + При наведении **кнопки "закрыть окно" и "в плейлист" не подсвечиваются**;
  + При наведении на плейлист **имя плейлиста подчеркивается**:<br>
  ![pleer10](img/pleer/pleer10.png)
  + Если модальное окно открыто, то плеер должен блокироваться;
> [!WARNING]
> БАГ. Если модальное окно открыто, плеер не блокируется, поэтому можно открыть еще одно модальное окно повторным нажатием на кнопку "в плейлист".
  + При нажатии на кнопку закрыть, **модальное окно закрывается**;
* При нажатии на кнопку "поделиться" открывается модальное окно с доступными способами отправки треков:<br>
![pleer11](img/pleer/pleer11.png)
  + При наведении **кнопки "VK", "Telegram", "Копировать ссылку",  "Отмена" не подсвечиваются**;
  + При нажатии на кнопку "VK" происходит редирект на страницу шеринга ВК;
  + При нажатии на кнопку "Telegram" происходит редирект на страницу шеринга Telegram;
  + При нажатии на кнопку "Копировать ссылку" **текст меняется на "Ссылка скопирована" и ссылка добавляется в буфер обмена**;
    - При нажатии на кнопку "Ссылка скопирована" **текст меняется на "Копировать ссылку"**;
  + При нажатии на кнопку "VK" **открывается сайт ВК, где можно  поделиться треком**;
  + При нажатии на кнопку "Telegram" **открывается сайт Telegram, где можно поделиться треком**;
  + Если модальное окно открыто, то плеер должен блокироваться;
> [!WARNING]
> БАГ. Если модальное окно открыто, плеер не блокируется, поэтому можно открыть еще одно модальное окно повторным нажатием на кнопку "поделиться".
  + При нажатии на кнопку закрыть, **модальное окно закрывается**.

### Регулирование громкости

В правой части плеера находится слайдер, с помощь которого можно регулировать громкость трека.

* При перемещении ползунка **громкость трека изменяется**;
* При нажатии на кнопки, расположенные по бокам слайдера, **уровень громкости трека должен изменяться**:
> [!WARNING]
> БАГ. При нажатии на кнопки, расположенные по бокам слайдера, уровень громкости не изменяется.<br>
![pleer12](img/pleer/pleer12.png)
* Если сдвинуть ползунок слайдера в крайнее левое положение **трек не должно быть слышно**;
> [!WARNING]
> БАГ. Если сдвинуть ползунок слайдера в крайнее левое положение трек будет слышен.
* При маленьком значение ширины дисплея **слайдер уровня громкости должен присутствовать**:
> [!WARNING]
> БАГ. При маленьком значение ширины дисплея слайдер уровня громкости исчезает.<br>
![pleer13](img/pleer/pleer13.png)
* Можно использовать "стрелки" для регулирования уровня громкости;
* Уровень громкости должен сохраняться после перезагрузки страницы;
> [!WARNING]
> БАГ. Уровень громкости не сохраняется после перезагрузки страницы<br>

# Отчет о тестировании музыкального сервиса NovaCode

Ссылка: [nova-music.ru](http://nova-music.ru)

## 2. Навбар

#### Тестовое окружение

- Браузер: Safari. Version 18.3 (20620.2.4.11.5)

### 2.1 Левая секция навбара

В левой секции навбара присутствует логотип сервиса, название и несколько ссылок, которые осуществляют навигацию  по сайту: переход на главную страницу, переход на страницу поиска.

1. При нажатии на кнопку "Главная" отображается главная страница, а кнопка "Главная" подчеркивается оранжевым цветом
![2-1-1](img/navbar/2-1-1.png)

2. При нажатии на кнопку "Поиск" отображается страница поиска, а кнопка "Поиск" подчеркивается оранжевым цветом
![2-1-2](img/navbar/2-1-2.png)

3. При нажатии на название или логотип сервиса отображается главная страница
> [!WARNING]
> БАГ. На логотип нельзя нажать.

4. При наведении на название сервиса, кнопку "Главная", "Поиск" текст кнопки затемняется
![2-1-3](img/navbar/2-1-3.png)

5. При уменьшении размера ширина экрана/браузера, а также на мобильных устройствах кнопки "Главная", "Поиск"  скрываются и перемещаются в sidebar справа
![2-1-4-1](img/navbar/2-1-4-1.png)
![2-1-4-2](img/navbar/2-1-4-2.png)

### 2.2 Правая секция навбара неавторизованного пользователя

Для неавторизованного пользователя в правой секции навбара располагаются кнопки "Войти", "Регистрация" для перемещения на соответствующие страницы.

1. При нажатии на кнопку "Войти" отображается страница авторизации, а кнопка "Войти" подчеркивается оранжевым цветом
![2-2-1](img/navbar/2-2-1.png)

2. При нажатии на кнопку "Регистрация" отображается страница регистрации, а кнопка "Регистрации" подчеркивается оранжевым цветом
![2-2-2](img/navbar/2-2-2.png)

3. При уменьшении размера ширина экрана/браузера, а также на мобильных устройствах кнопки "Войти", "Регистрация"  скрываются и перемещаются в sidebar справа
![2-2-3-1](img/navbar/2-2-3-1.png)
![2-2-3-2](img/navbar/2-2-3-2.png)

### 2.3 Правая секция навабара авторизованного пользователя

Для авторизованного пользователя в правой секции навбара располагаются кнопка "Выход" для выхода из аккаунта профиля и аватарка пользователя, при нажатии на которую отображается страница профиля пользователя.

1. При нажатии на аватарку пользователя отображается страница профиля пользователя
![2-3-1](img/navbar/2-3-1.png)

2. При нажатии на кнопку "Выход" отображается модальное окно подтверждения выхода из аккаунта пользователя
![2-3-2](img/navbar/2-3-2.png)

3. При наведении на кнопку "Выход" текст кнопки затемняется
![2-3-3](img/navbar/2-3-3.png)

### 2.4 Sidebar

Компактная навигационная панель, отображающася при уменьшении ширина браузера или на мобильных устройствах.

1. При нажатии на правую кнопку в навбаре отобразится sidebar с кнопкакми "Главная", "Поиск", "Профиль", "Войти" и "Регистрация" (для неавторизованного пользователя), "Выход" (для авторизованного пользователя)
![2-4-1](img/navbar/2-4-1.png)
> [!WARNING]
> БАГ. Для неавторизованного пользователя всегда отображается кнопка "Выход", вместо кнопок "Войти" и "Регистрация"

2. При нажатии на кнопку "Главная", "Поиск", "Профиль", "Войти", "Регистрация", "Выход" отображается соответствующая страница, а сама кнопка подчеркивается оранжевым цветов
![2-4-2](img/navbar/2-4-2.png)

3. При наведении на кнопку "Главная", "Поиск", "Профиль", "Войти", "Регистрация", "Выход" текст затемняется
![2-4-3](img/navbar/2-4-3.png)

4. При нажатии на крестик в левом верхнем углу панель sidebar скрывается

5. Sidebar не скрывается при нажатии на область вне панели

### 2.5 Модальное окно подтверждения выхода

Модальное окно для подтверждения выхода из аккаунта пользователя.

1. При нажатии на кнопку "Да, выйти" происходит выход из аккаунта и редирект на страницу авторизации
![2-5-1](img/navbar/2-5-1.png)

2. При наведении на кнопку "Да, выйти" затемнение кнопки не происходит
![2-5-2](img/navbar/2-5-2.png)

3. При наведении на кнопку "Отмена" выделение кнопки не происходит
![2-5-3](img/navbar/2-5-3.png)

4. Модальное окно не скрывается при нажатии на область вне этого окна

5. При открытии модального окна происходит затемнение страницы
![2-5-5](img/navbar/2-5-5.png)

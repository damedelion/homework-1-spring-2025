# Отчет о тестировании музыкального сервиса NovaCode

Ссылка: [nova-music.ru](http://nova-music.ru)

## 1. Поиск

#### Тестовое окружение

- Браузер: Safari. Version 18.3 (20620.2.4.11.5)

### 1.1 Строка поиска

Место ввода поискового запроса, под которым располагается кнопка "Искать".

1. При клике на строку поиска происходит выделение инпута синим
![1-1-1](img/search/1-1-1.png)

2. При вводе символов в поисковую строку подсказки не появляются
![1-1-2](img/search/1-1-2.png)

3. Если в стркое поиска введен запрос, то снизу, в блоке с результатом поиска, отображаются совпадения
![1-1-3](img/search/1-1-3.png)

4. При наведении на кнопку "Искать" затемнения/выделения не происходит

5. При клике на кнопку "Искать" затемнения/выделение не происходит

6. Если нажать на кнопку "Искать" и если в поисковой строке ничего нет, то отобразится подсказка "Заполните это поле" на языке браузера
![1-1-6](img/search/1-1-6.png)

7. При вводе в строку поиска запроса, содержащего цифры, отображаются найденные совпадения (если они есть)
![1-1-7](img/search/1-1-7.png)

8. При вводе в строку поиска запроса на русском языке отображаются найденные совпадения (если они есть)
![1-1-8](img/search/1-1-8.png)

9. При воде в строку поиска запроса, содержащего символы из utf, отображаются найденные совпадения (если они есть)
![1-1-9](img/search/1-1-9.png)

10. Нажатие на клавишу "Enter" инициирует логику поиска

11. Ввод длинного запроса (32901 символа) не ломает поиск
![1-1-11-1](img/search/1-1-11-1.png)
![1-1-11-2](img/search/1-1-11-2.png)

12. При вводе пробелов в строку поиска отображается панель "Ничего не найдено"
![1-1-12](img/search/1-1-12.png)

### 1.2 Блок с результатом поиска

Раздел страницы, содержащий три блока с найденными совпадениями для артистов, треков и альбомов.

1. Если в блоке с результатом поиска отображаются совпадения и если в строке поиска ввесит запрос и нажать кнопку "Искать", то в блоке с результатом будет отображаться совпадения для нового запроса

> [!WARNING] БАГ
> Если в блоке с результатом поиска уже отображаются совпадения, среди который есть совпадения с треком, и если ввести новый запрос, для которого не будет найдено ни одного трека (при этом альбом или артист может быть найден), то в блоке с результатом появится трек/треки, относящиеся к последнемоу запросу, для которого был найден трек/треки.
> ![1-2-1-1](img/search/1-2-1-1.png)
> ![1-2-1-2](img/search/1-2-1-2.png)

2. Если в поисковой строке ввести запрос, для которого не будет ничего найдено, то отобразится блок с надписью "Ничего не найдено" и подсказкой "Попробуйте поискать что-то другое."
![1-2-2](img/search/1-2-1.png)

3. При загрузке страницы блок скрыт

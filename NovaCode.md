# Отчет о тестировании музыкального сервиса NovaCode

Ссылка: [nova-music.ru](http://nova-music.ru)

## Поиск

#### Тестовое окружение

- Браузер: Safari. Version 18.3 (20620.2.4.11.5)

### Строка поиска

Место ввода поискового запроса, под которым располагается кнопка "Искать".

- При клике на строку поиска происходит выделение инпута синим
![1-1-1](img/search/1-1-1.png)

- При вводе символов в поисковую строку подсказки не появляются
![1-1-2](img/search/1-1-2.png)

- Если в стркое поиска введен запрос, то снизу, в блоке с результатом поиска, отображаются совпадения
![1-1-3](img/search/1-1-3.png)

- При наведении на кнопку "Искать" затемнения/выделения не происходит

- При клике на кнопку "Искать" затемнения/выделения не происходит

- Если нажать на кнопку "Искать" и если в поисковой строке ничего нет, то отобразится подсказка "Заполните это поле" на языке браузера

![1-1-6](img/search/1-1-6.png)

- При вводе в строку поиска запроса, содержащего цифры, отображаются найденные совпадения (если они есть)
![1-1-7](img/search/1-1-7.png)

- При вводе в строку поиска запроса на русском языке отображаются найденные совпадения (если они есть)
![1-1-8](img/search/1-1-8.png)

- При вводе в строку поиска запроса, содержащего символы из utf, отображаются найденные совпадения (если они есть)
![1-1-9](img/search/1-1-9.png)

- Нажатие на клавишу "Enter" инициирует логику поиска

- Ввод длинного запроса (32901 символа) не ломает поиск
![1-1-11-1](img/search/1-1-11-1.png)
![1-1-11-2](img/search/1-1-11-2.png)

- При вводе пробелов в строку поиска отображается панель "Ничего не найдено"
![1-1-12](img/search/1-1-12.png)

- Регистр символов введенной строки не влияет на результат поиска
![1-1-13-1](img/search/1-1-13-1.png)
![1-1-13-2](img/search/1-1-13-2.png)

### Блок с результатом поиска

Раздел страницы, содержащий три блока с найденными совпадениями для артистов, треков и альбомов.

- Если в блоке с результатом поиска отображаются совпадения и если в строке поиска ввести запрос и нажать кнопку "Искать", то в блоке с результатом будут отображаться совпадения для нового запроса

> [!WARNING]
> БАГ. Если в блоке с результатом поиска уже отображаются совпадения, среди которых есть совпадения с треком, и если ввести новый запрос, для которого не будет найдено ни одного трека (при этом альбом или артист может быть найден), то в блоке с результатом появится трек/треки, относящиеся к последнему запросу, для которого был найден трек/треки.
> ![1-2-1-1](img/search/1-2-1-1.png)
> ![1-2-1-2](img/search/1-2-1-2.png)

- Если в поисковой строке ввести запрос, для которого не будет ничего найдено, то отобразится блок с надписью "Ничего не найдено" и подсказкой "Попробуйте поискать что-то другое."
![1-2-2](img/search/1-2-2.png)

- При загрузке страницы блок скрыт

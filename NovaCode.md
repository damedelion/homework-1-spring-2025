## Плеер

#### Тестовое окружение

- Браузер: Mozilla Firefox 135.0

### Воспроизведение трека (левая часть)

В левой части плеера есть три функциональные кнопки: "предыдущий трек", "воспроизведение/пауза", "следующий трек".

* При наведение, кнопки: "предыдущий трек", "воспроизведение/пауза", "следующий трек", **затемняются**:
![pleer1](img/pleer/pleer1.png)
* При нажатие на кнопку "предыдущий трек" **начинает играть предыдущий трек**;
* Если трек не играет, то при нажатие на кнопку "воспроизведение/пауза", он **начинает играть, изображение кнопки меняется**:
![pleer2](img/pleer/pleer2.png)
* Если трек играет, то при нажатие на кнопку "воспроизведение/пауза", он **ставится на паузу, изображение кнопки меняется**:
![pleer3](img/pleer/pleer3.png)
* При нажатие на кнопку "следующий трек" **начинает играть следующий трек**;
* При переключение трека **меняется информация о треке (автор, название трека, картинка)**.

### Воспроизведение трека (слайдер)

Слева от слайдера отображается текущее время трека, а справа — его общая длительность.

* Когда играет трек, **ползунок слайдера меняет свое положение**:
![pleer4](img/pleer/pleer4.png)
* Когда играет трек, **текущее время трека изменяется**:
* Если сдвинуть ползунок, то **время не изменится**:
![pleer5](img/pleer/pleer5.png)
* Если сдвинуть ползунок, а потом нажать на кнопку "воспроизведение/пауза" **время изменится**;
* Если во время воспроизведения сдвинуть ползунок, **трек начнет играть с новой позиции**;
* Обводка плеера **не равномерная**:
![pleer6](img/pleer/pleer6.png)

### Взаимодействие с треком

Справа от информации о треке, есть три функциональные кнопки: "лайк", "в плейлист", "поделиться".

* При наведение, кнопки: "лайк", "в плейлист", "поделиться", **затемняются**:
![pleer7](img/pleer/pleer7.png)
* Если трек лайкнут, то кнопка "лайк" **затемнена и трек добавляется в любимые треки пользователя**:
![pleer8](img/pleer/pleer8.png)
  + Если трек лайкнут, то при наведение **внешний вид кнопки лайк не изменяется**; 
  + Если трек лайкнут, то при нажатие на кнопку "лайк" перестает затемняться и **трек удаляется из любимых треков пользователя**;
* При нажатие на кнопку "в плейлист", **открывается модальное окно для выбора плейлиста**:
![pleer9](img/pleer/pleer9.png)
  + При наведение **кнопки "закрыть окно" и "в плейлист" не подсвечиваются**;
  + При наведение на плейлист **имя плейлиста подчеркивается**:
  ![pleer10](img/pleer/pleer10.png)
  + Если модальное окно открыто, то нажатие на кнопку "в плейлист" **откроет новое модально окно поверх уже открытого**;
  + При нажатие на кнопку закрыть, **модальное окно закрывается**;
* При нажатии на кнопку "поделиться" открывается модальное окно с доступными способами отправки треков:
![pleer11](img/pleer/pleer11.png)
  + При наведение **кнопки "VK", "Telegram", "Копировать ссылку",  "Отмена" не подсвечиваются**;
  + При нажатие на кнопку "Копировать ссылку" **текст меняется на "Ссылка скопирована" и ссылка добавляется в буфер обмена**;
    - При нажатие на кнопку "Ссылка скопирована" **текст меняется на "Копировать ссылку"**;
  + При нажатие на кнопку "VK" **открывается сайт ВК, где можно  поделиться треком**;
  + При нажатие на кнопку "Telegram" **открывается сайт Telegram, где можно поделиться треком**;
  + Если модальное окно открыто, то нажатие на кнопку "поделиться" **откроет новое модально окно поверх уже открытого**;
  + При нажатие на кнопку закрыть, **модальное окно закрывается**.

### Регулирование громкости

В правой части плеера находится слайдер, с помощь которого можно регулировать громкость трека.

* При перемещение ползунка **громкость трека изменяется**;
* При нажатие на кнопки расположеные по бокам слайдера **громкость не изменяется**
![pleer12](img/pleer/pleer12.png);
* Если сдвинуть ползунок слайдера в крайнее левое положение **трек будет слышен**;
* При маленьком значение ширины дисплея **слайдер пропадает**;
![pleer13](img/pleer/pleer13.png)
